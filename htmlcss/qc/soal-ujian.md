apa kepanjangan html: hypertext markup language
apa kepanjangan css: cascading stylesheet
apa itu cdn: content delivery network
apa itu tailwind: framework yg berisi css siap pakai
bagaimana cara menggunakan tailwind: <script src="https://cdn.tailwindcss.com"></script>
apa itu elemen semantic di html: elemen yg mendeskripsikan makna dan tujuan kontennya
sebutkan 7 elemen semantic = header, main, footer, a, nav, section, article, strong, h1, p 
apa itu html attribute dan contohnya: informasi tambahan pada tag pembuka, contohnya class, style, href, src, id
apa itu css property dan contohnya: styling yg diinginkan untuk elemen, contohnya color, background-color, font-family, font-size, font-weight, font-style
css dari pemanggilannya terbagi 3: inline, internal, eksternal
disebut css inline krn: dipanggil langsung di tag pembuka elemen html
disebut css internal krn: dipanggil di elemen head 
disebut css eksternal krn: dipanggil dari file css terpisah 
apa itu css selector, dan contohnya: kode pada css yg digunakan sebagai penanda sebuah styling, contohnya . dengan class, # dengan id, atau nama elemen langsung
fungsi font-family: mengubah jenis font, contohnya arial, helvetica, serif, sans-serif
fungsi font-size: mengubah ukuran font, value nya bisa px, rem, %, dst.
fungsi font-weight: mengubah ketebalan font, valuenya angka saja, contoh 100, 500, 900
fungsi font-style: mengubah gaya font, contohnya italic, oblique
