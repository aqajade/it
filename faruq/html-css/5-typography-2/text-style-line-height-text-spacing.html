Text style - Line height - Text Spacing

text-align untuk merubah kerataan teks, rata tengah, kiri, kanan, maupun kirikanan - center,left,right,justify

text-decorationuntuk merubah dekoasi text, values populernya underlinde, line-through, none

line-height untuk merubah tinggi baris teks

word-spacing untuk merubah jarak antar kata

letter-spacing untuk merubah jarak antar huruf
